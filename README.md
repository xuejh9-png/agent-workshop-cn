## 可以验收

首页输入目标；执行方式与依赖模型的示例选择；发送/停止；侧栏设计示例；演示运行/审批/失败/交付状态；批准/拒绝、失败重试、验收/返工；按需任务详情、文件预览与审核记录；工作空间切换、策略保存；附件选择与移除（仅名称，不读取、不上传）；浅深色；375/768/1024/1440 响应式。

所有任务、模型、工具事件、交付文件和审核都是 DEMO。状态由演示按钮推进，不伪装真实执行。模型名称是语义示例，非静态编造的账号能力列表。任务和选择保存在本浏览器 localStorage；仅适用于演示，不作正式持久化。

`/api/capabilities` 只检测固定名单 `codex`、`claude`、`codebuddy` 命令及 `--version`，每个命令最多 5 秒。不读取凭据或模型配置，不启动模型任务；安装状态不等于登录、额度或模型权限。CodeBuddy CLI 不等于 WorkBuddy 桌面。

## 设计说明

依据 Context Hub `affb63f2664c57f3701615373a6df599b028218d` 中 AW-D-004/005 和 FRONTEND_SPEC_V1_0。暖白画布 #F8F8F7、白色内容面、深灰正文 #202124，紫色 #7965D8 用于焦点和运行状态。系统中文字体，正文 14–15px，内容最大 820px，侧栏 240px；4/8/12/16/24/32 间距、8–14px 圆角。深色提供完整色彩变量与键盘焦点。

861px 以上侧栏参与布局；更窄默认收起，以遮罩打开。详情默认关闭，以覆盖式抽屉展示，小屏铺满主内容；隐藏抽屉和导航 inert，弹窗用原生 dialog 管理焦点。执行器和模型在输入框底部，彼此关联；运行时改动只作用于下次演示任务。

保留：Claude 写下的方案 B 布局、基础样式、系统字体和 SVG（原始内容在首个 Git 提交）。调整：字体对比度、点击范围、弹层和侧栏断点。替换：不闭环的任务脚本、占位提示、模拟“已连接/已核对”断言。更早 v0.1 ZIP 未找到，后端 SQLite/API 等不能据此判断保留或替换。
