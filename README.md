# Agent Studio · 本地工程工作名

沿用负责人已通过的方案 B。当前支持项目经理、授权员工、多项目对话，以及指定源码快照、独立审核、逐文件确认写入和撤销。完整 v1.2 最终验收仍未完成。名字与品牌延后。

## 启动

要求：Python 3.11+、已登录的 Codex CLI。本机实测版本 `0.165.0-alpha.1.2`。

```
python3 server.py
```

打开 http://127.0.0.1:8891 。只绑定本机，不自动部署。数据在被 Git 忽略的 `.studio/`：SQLite 运行/设置、工作空间文件、只含操作路径和大小的审计记录。不要把此目录提交到 GitHub。

使用本机服务地址打开工作台；直接双击 `index.html` 会自动跳转到上述地址，服务仍需先启动。HTML文件本身不能独立保存项目或发送对话。

首次使用：设置→连接及验证→测试具体型号（一次真实调用会使用额度）→分别保存项目经理、员工与审核配置。候选目录不等于有权限；验证绑定宿主、账号、连接配置和型号。输入框只选择经理宿主和本次允许员工，型号和强度在设置中预配。运行中变更只影响下次请求。

项目经理直接回答或委派给本次勾选的员工；简单问答只调用经理一次，不创建多步卡。后端先校验整份授权计划，再顺序执行最多四个员工步骤；每步独立保存，失败或取消保留已完成部分。

附件与项目知识支持真实 UTF-8 md/txt、每份 256KB；应用内资料仍只允许新建，不能覆盖。模型需通过受限文件工具读取，详情记录来源；产物可以真实预览。

项目侧栏的「本机项目与源码」可绑定明确授权的目录，每次选择 1–12 个源码文件、合计不超过 512KB。员工只读写隔离快照；在任务详情中查看差异、启动独立只读审核，通过后逐文件确认写入，支持撤销。隐藏目录、凭据类文件、依赖、构建目录及链接不开放。当前只替换已选文件，不创建/删除原项目文件，不执行 Shell、自动测试或发布；不默认访问 YiPex/Investment OS。

## 接入和安全边界

- Codex CLI 使用当前已登录身份，未读取/复制密钥，未改用户全局配置。自有临时 `studio_https` provider 仅切换 HTTPS、沿用官方 OpenAI 身份，避免本机 WebSocket 重试延迟，不更换请求模型。
- 用户/项目插件、Hooks、Shell、浏览器、应用与子 Agent 等能力显式关闭；不加载用户 config。执行器仅挂载自有受限 `studio_files` MCP；主控不挂载文件工具。无危险跳过沙箱参数。
- 受限工具保持逐级 O_NOFOLLOW、拒绝硬链接/特殊文件、根目录描述符和调用次数上限。源码权限按项目和本次文件集合固化；模型不能直接覆盖原项目。审核使用新会话，只接收目标、原文、diff 和后端操作证据；静态审核不等于测试通过。
- 原文件写入使用系统原子交换，保留被换出的文件版本；交换后检测并发保存，归档或恢复失败时保留准确恢复路径。恢复版本在本机 `.studio/source-backups/`，不会提交。其他编辑器持续持有旧文件描述符时，恢复文件仍可能被继续写入，不能视为不可变快照；操作期间应暂停其他编辑器写入。跨磁盘归档和不支持原子交换的系统拒绝写入。
- HTTP 检查精确 Host、Origin、跨站来源和每进程令牌；没有跨域放行。CLI 通过参数列表与 stdin 调用，不将任务拼入 Shell。
- 取消终止进程组与 MCP 子进程。取消不自动回滚文件；失败/重启不会自动重试写操作。服务重启后遗留运行标记中断。前端从后端读取状态，不依赖 localStorage 假运行。
- 保留后端步数风控；用量来自各 CLI，未回传金额或实际型号时显示未知。CLI 报告金额并非账户账单；WorkBuddy 报 0 不代表已核实免费。更换 Claude/WorkBuddy 凭据会使旧验证失效。
